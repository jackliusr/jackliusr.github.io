Login in as kubeadmin in openshift local, Ecosystem--> Software Catalog, Search "AI" and install "Red Hat OpenShift AI"


[source,bash]
----
# default unit MiB
crc config set memory 32000
crc stop
crc start

----

OpenShift AI Operator Installation
Prerequisite Operators: Navigate to OperatorHub in the OpenShift web console and install required dependencies including Logical Volume Manager Storage (LVMS) and Node Feature Discovery (NFD).

 Ensure your host machine has at least 4 physical CPU cores, 16 GB to 32 GB of RAM, and roughly 30 GB to 35 GB of free disk space.
